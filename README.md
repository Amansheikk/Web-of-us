# OUR LITTLE UNIVERSE ❤️
### A Cinematic, Interactive Storytelling Website

A luxury editorial, emotionally resonant, cinematic storytelling website celebrating our journey through authentic photographs, words, and memories.

---

## 🌟 Visual & Creative Direction
- **Atmosphere**: Cinematic film, vintage luxury editorial, intimate and deeply personal.
- **Color Palette**:
  - Primary Background: `#0D0C13`
  - Primary Typography: `#E9D9C5` (Warm Ivory)
  - Antique Gold Accent: `#B89B72`
  - Deep Midnight Blue: `#071B32`
  - Dark Olive Green: `#303527`
  - Secondary Text: `#BEB3A5`
  - Subtle Dark Overlays: `rgba(0, 0, 0, 0.45)`
- **Typography System**:
  - `Cormorant Garamond` (Oversized editorial headings)
  - `Playfair Display` (Secondary editorial accents)
  - `Inter` (Body and minimal UI elements)

---

## 📖 The Five Chapters
1. **CHAPTER 01: WHERE IT ALL STARTED**
   - Full viewport Alva's college photograph backdrop with subtle Ken Burns slow zoom and 35mm film grain.
   - Antique gold horizon line and warm ivory typography.
   - Minimal scroll indicator leading into the story.
2. **CHAPTER 02: A BIG THANK YOU TO RAMADAN & ALLAH**
   - Deep midnight blue celestial atmosphere with delicate floating golden star particles.
   - Authentic Ramadan crescent moon and lanterns artpiece preserved in an antique gold frame.
   - Peaceful and grateful two-stage title reveal.
3. **CHAPTER 03: OUR INSTAGRAM MEMORIES**
   - Custom-crafted luxury messaging interface with dark olive user bubbles (`#303527`) and dark charcoal her bubbles (`#1C1B24`).
   - Progressive conversation animation with realistic typing indicators and natural pauses.
   - Accurate date badge: `29 APRIL 2024`.
   - Dedicated replay button to relive the conversation.
4. **CHAPTER 04: THE TELEPHONES KNOW EVERYTHING ABOUT US**
   - Alva's coin box telephone photograph with vintage color grading and warm brown lighting.
   - 3-line word reveal: `THE TELEPHONES / KNOW EVERYTHING / ABOUT US.`
   - Interactive vintage twin-gong telephone ring audio synthesizer (toggleable, never autoplays).
5. **CHAPTER 05: AND THIS IS ONLY THE BEGINNING**
   - Deep midnight black with ambient antique gold starlight.
   - Oversized luxury serif typography with generous negative space.
   - Closing quote: *"A little more of us, still waiting to be written."*
   - Smooth restart button: `↻ EXPERIENCE OUR STORY AGAIN`.

## 🚀 How to Run Locally

### Option 1: Instant Local Preview (Zero Installation Required)
Using Python (already installed on your machine):
```powershell
cd "C:\Web us"
python -m http.server 3000
```
Then open your browser at:
👉 **http://localhost:3000**

You can also simply double-click `C:\Web us\index.html` to open directly in Chrome, Edge, or Firefox!

### Option 2: Vite / React / TypeScript Workflow
If Node.js is installed on your system in the future:
```bash
npm install
npm run dev
```
To create a production build:
```bash
npm run build
```
